\subsection{A closed-form condition for ranking inversion}\label{sec:m-law}
Stratifying the leaky test set by maximum similarity to training into a leaked stratum (similarity $\ge0.9$, fraction $\varphi$) and a novel stratum ($<0.5$) gives, for any model $M$ with leaked-stratum accuracy $h_M$ and novel-stratum accuracy $n_M$, the two-stratum identity $a_M=n_M+\varphi g_M$ with $g_M=h_M-n_M$ the graded memorization gap of \S4.4, so the split-induced drop is the product $\Delta_M=\varphi g_M$. For an ordered pair $(A,B)$ with $A$ the leader on the as-shipped split, writing $\delta=n_B-n_A$ for $B$'s true novel-sequence advantage and $\Delta g=g_A-g_B$ for $A$'s excess memorization propensity, the as-shipped margin is $\mu=a_A-a_B=\varphi\Delta g-\delta$. The benchmark therefore reports the wrong winner exactly when $0<\delta<\varphi\Delta g$, i.e.\ when $\varphi$ exceeds the \emph{ranking breakdown point}
\begin{equation}\varphi^{*}=\delta/\Delta g.\label{eq:phistar}\end{equation}
We stress that the algebraically equivalent form $0<\mu<\Delta_A-\Delta_B$ carries \emph{no} predictive content: substituting $\Delta_M=a_M-a_M^{\mathrm{corr}}$ reduces it to $a_B^{\mathrm{corr}}>a_A^{\mathrm{corr}}$, which is the definition of a corrected-split inversion restated. We compute it only as an arithmetic-consistency check on our own tables, where it must hold $12/12$ by algebra. All predictive content lies in \eqref{eq:phistar}, whose inputs $(\varphi,n,g)$ are measured on the as-shipped split alone and never touch the corrected split. Uncertainty on $\delta$ and on the inversion margin $m_{\mathrm{inv}}=\varphi\Delta g-\delta$ comes from the same cluster (block) bootstrap used in \S4.9, resampling whole within-test near-duplicate components, $10{,}000$ replicates; a pair is \textsc{clean}-inverting when both CIs exclude zero and \textsc{fragile} when the $\delta$ CI straddles zero.

\subsection{Coordinate-space construction signatures}\label{sec:m-coord}
Genomic Benchmarks ships per-sequence intervals (\texttt{id,region,start,end,strand}) separately from the sequences its loader returns. We recover them offline and realign them to loader row order, which is deterministic (\texttt{split}, then sorted class directory, then sorted filename, the filename stem being the interval \texttt{id}); recovered interval width equals sequence length for $100\%$ of rows in all eight datasets, and where the extracted files are present the recovered order matches the true filenames exactly. Because these coordinates are causally upstream of, and statistically independent from, the $k$-mer clustering that measures leakage, they furnish a genuinely cross-modal test rather than a restatement. Per class we compute self-overlap redundancy $R_{\mathrm{self}}=1-n_{\mathrm{merged}}/n_{\mathrm{raw}}$, the share of intervals sharing $\ge t$ reciprocal overlap with another interval of the same class, and the share of \emph{test} intervals overlapping any \emph{train} interval at $\ge t$ reciprocal overlap, for $t\in\{{\ge}1\,\mathrm{bp},0.5,0.9,1.0\}$. Overlap is strand-agnostic throughout, since strand is unrecorded for \textit{human\_ocr\_ensembl} and \textit{human\_ensembl\_regulatory}. The construction rule thresholds the maximum over classes of the $\ge50\%$ reciprocal cross-split statistic at $0.1$---the same cut already used for the sequence-space verdict---so it introduces no fitted parameter.

\subsection{Construct-and-break manipulations}\label{sec:m-manip}
To test the construction rule causally rather than correlationally we intervene on the construction step alone. \emph{Break-a-clean}: \textit{human\_ocr\_ensembl}, drawn from the merged Ensembl Regulatory Build and clean by every measure, is rebuilt the way an un-merged multi-sample union is built, by duplicating the same $94.3\%$ share of positive rows that we measure on \textit{human\_enhancers\_ensembl}. \emph{Fix-a-leaky}: \textit{human\_enhancers\_ensembl} receives the merge step its curators omitted---every duplicated coordinate collapsed to a single representative row---with sequences, labels, model code and split ratio unchanged. Each manipulation is paired with an unmanipulated control run of the identical pipeline at the same scale and split seed, so any difference is attributable to the intervention rather than to re-splitting or model variance.

\subsection{Cross-suite leak census}\label{sec:m-census}
We apply the census step of \S4.1 unchanged to the Nucleotide Transformer downstream tasks, which exist in two releases by the same authors: the original and a revised release whose card states that it "replaced randomly generated negative samples by existing chunks of genomes" and gave "all datasets proper chromosome held-out test sets." Because the two releases share task names, the pair isolates curation from biology. Training sets are capped at $20{,}000$ sequences; capping can only remove potential near-duplicate partners, so every reported fraction is a lower bound---the same direction of error that makes our own \textit{demo\_coding} verdict tighten, not loosen, at full scale.

\subsection{The \texttt{certify} protocol}\label{sec:m-certify}
We package the audit as an executable standard with eight checks: run at full scale; report both length-blind and length-robust leak fractions; confirm with an alignment engine; include a memorization-prone model as a tripwire; certify on the graded gap and label concordance rather than accuracy; run a matched random re-split control; put cluster-bootstrap intervals with ICC and design effect on every delta; and, where coordinates ship, apply the construction rule of \S\ref{sec:m-coord}. A green verdict carries the heavier evidential burden: a dataset is certified clean only when every applicable check passes, whereas one failing check flags it. The tripwire may escalate a verdict only when the high-similarity bin exceeds the $n\ge50$ confidence floor used in \S4.4 \emph{and} the homology-corrected drop exceeds the matched random re-split drop, so that ordinary repartitioning cost is never mistaken for leakage.

\subsection{A closed-form condition predicts when leakage reorders a ranking}\label{sec:r-law}
% inversion_law_{anchors,pairs,winner,regpath,inject,critical_f,bootstrap}.csv
We first separate what the identity asserts from what it predicts. The reconstruction $a=n+\varphi g$ is an \emph{identity}, not a forecast: $a_{\mathrm{orig}}$ is the bin-weighted mean of the very same graded accuracies, so the multi-bin form is exact by construction (residual $10^{-4}$), and the two-bin residual---$0.0020$ on \textit{human\_enhancers\_ensembl} versus $0.0175$ on \textit{human\_nontata\_promoters}---measures only how much accuracy mass the mid-similarity bins carry ($1.4\%$ versus $22.4\%$ of the test set). Its value is that it licenses \eqref{eq:phistar}, whose content \emph{is} predictive. Applied to the marquee pair, $\delta=+0.0122$ and $\Delta g=0.1929$ give a breakdown point $\varphi^{*}\approx0.063$ against a measured $\varphi=0.380$---a sixfold exceedance---so \eqref{eq:phistar} predicts the observed random-forest-to-LinearSVC inversion, with cluster-bootstrap CIs excluding zero for both $\delta$ ($[0.0054,0.0192]$) and $m_{\mathrm{inv}}$ ($[0.0560,0.0663]$): \textsc{clean}. On \textit{human\_nontata\_promoters} every random-forest pair has $\delta\le0$, so the same inequality predicts no inversion \emph{on the novel stratum}, and no pair there is \textsc{clean}---which is why that dataset's accuracy-only demotion does not survive AUROC, $F_1$ or a novel-only evaluation (\S4.3). The genuinely out-of-sample claim is that the corrected-split winner is $\arg\max_M n_M$, decided without ever seeing the corrected split; it holds on $3/3$ metric readouts for \textit{human\_enhancers\_ensembl} and $2/3$ for \textit{human\_nontata\_promoters}, the sole disagreement being the accuracy readout \S4.3 independently flags as a dead heat. (A fourth readout, novel-only, is excluded from that tally because its ground truth is itself $\arg\max_M n_M$ and it is therefore true by construction.) The one assumption, $a^{\mathrm{corr}}\approx n$, fails informatively: retraining on the de-leaked set costs the memorizer far more than the others (residual $-0.074$ for the random forest on \textit{human\_enhancers\_ensembl} versus $+0.012$ to $+0.016$ for the other three), so the condition \emph{under}-predicts how far the forest falls. It is sufficient rather than necessary---high precision, low recall---and errs by missing inversions rather than by inventing them.

\subsection{The law forecasts the regularization path and the injection dose-response}\label{sec:r-oos}
% inversion_law_regpath.csv, inversion_law_inject.csv, inversion_law_critical_f.csv
Two sweeps already in hand exercise the condition with no fitted parameters. Along the $g$-axis, predicting the forest's as-shipped rank at each of the $22$ regularization cells of \S4.5 from $(\varphi,n,g)$ alone---$\varphi$ measured once per dataset, the three competitors fixed---matches the observed rank in $21/22$ cells and places the predicted crossover in $\texttt{min\_samples\_leaf}\in(5,20]$, exactly where it is observed. We label this an \emph{in-sample} result and read it conservatively: it restates the identity as an ordering on the same as-shipped test set rather than on held-out data, and $16$ of the $22$ cells are rank-$4$ blowouts where the nearest competitor is $0.012$--$0.086$ away, so the rank call is easy; the single miss is one of the few genuinely close cells. What it does establish is that the identity survives a twelve-fold change in $g$, which is the substance of the hyperparameter objection: we do not merely report that the sweep changes the result, we reproduce the sweep from the stratified quantities. Along the $\varphi$-axis the test is genuinely held out. The injected-leakage construction of \S4.13 has a leak fraction known by construction, $\varphi(f)=n_{\mathrm{inj}}/(n_{\mathrm{test}}+n_{\mathrm{inj}})$; fitting the leaked-stratum accuracy at $f=0.1$ \emph{only} yields $h_{\mathrm{RF}}=0.9988$---the memorization ceiling, expected \emph{a priori} to be $\approx1$ for near-exact copies---and $h_{\mathrm{LR}}=0.7096$, both invariant in $f$, and the held-out cells then follow to within $0.0011$ ($f=0.2$) and $0.0008$ ($f=0.4$). The implied breakdown point $\varphi^{*}=0.041$ corresponds to a critical injection $f^{*}=0.011$, and the observed random-forest-over-logistic-regression flip occurs between $f=0$ and $f=0.1$. We report that bracketing as a consistency check rather than a validated prediction, since the grid contains no cell between $0$ and $0.1$ and any $f^{*}$ in that interval would be bracketed equally well. The defensible statement is qualitative and still striking: contaminating a clean benchmark with roughly one percent of its own training data suffices to change which model wins.

\subsection{Coordinate geometry predicts which datasets leak}\label{sec:r-coord}
% construction_signatures.csv, construction_rule.csv, construction_provenance.csv
The maximum-over-classes cross-split coordinate overlap separates the suite cleanly: the two leaky datasets sit at $0.755$ and $0.992$, the six others at $0.073$ and below, a $10.3\times$ gap straddling the inherited $0.1$ threshold. Agreement with the sequence-space verdict is $7/8$ when \emph{borderline} is treated as its own level, and $8/8$ only if \emph{borderline} is folded into \emph{clean}; we report the strict figure, and the miss---\textit{demo\_coding\_vs\_intergenomic\_seqs}---is the dataset whose leakage is coding-paralog homology with no coordinate signature by construction. That dataset also bounds the rule's coverage: its \texttt{coding\_seqs} class is keyed by transcript accession, one distinct region per row, so no two intervals can overlap and its coordinate statistics are structurally zero---absence of measurement, not evidence of cleanliness. The decisive comparison is internal to Ensembl, holding provider and organism constant so that only the merge step differs: \textit{human\_enhancers\_ensembl} ships $77{,}421$ positives on only $40{,}934$ unique coordinates, with $94.3\%$ of positive rows sitting on a duplicated coordinate and $75.5\%$ of test positives having their exact coordinate present in training, whereas \textit{human\_ocr\_ensembl} and \textit{human\_ensembl\_regulatory}, drawn from the merged "MultiCell" Regulatory Build, sit at $0.000$--$0.010$. Every one of the $36{,}487$ duplicated-coordinate groups carries byte-identical sequences and a single label, so the coordinate redundancy \emph{is} the sequence redundancy. We are deliberately conservative about mechanism: although this set is documented as FANTOM5-derived, its measured signature---multiplicity capped at exactly two with identical boundaries---is not what a union over hundreds of independently-called tracks would produce, so we claim only what the data shows, that each interval is shipped exactly twice with no deduplication step. Quantitatively, the coordinate-predicted leak fraction for \textit{human\_enhancers\_ensembl} is $0.3776$ against a measured sequence leak of $0.3802$---agreement to $0.26$ percentage points from two independent modalities---while on \textit{human\_nontata\_promoters} the same predictor over-shoots, $0.3434$ against $0.2254$, because $\ge90\%$ reciprocal overlap of a $251$\,bp window still leaves enough novel $8$-mers to fall below the $0.9$ Jaccard cut. Coordinates therefore classify reliably but calibrate only under exact duplication. Two refinements were forced on us by the data and both matter. First, redundancy is not always in the positive class: \textit{human\_nontata\_promoters} carries essentially all of its redundancy in the \emph{negative} class ($R_{\mathrm{self}}=0.961$ versus $0.047$ for positives), so a positive-class-only statistic misses it entirely. Second, mere adjacency over-calls: \textit{drosophila\_enhancers\_stark} tiles at $2142$\,bp median length with base-pair-scale touches, giving $0.406$ at ${\ge}1$\,bp but $0.036$ at $\ge50\%$ reciprocal overlap, so without the reciprocal criterion the rule would produce a false positive. The two leaky datasets moreover leak by \emph{different} coordinate mechanisms---exact duplication on \textit{human\_enhancers\_ensembl} ($0.755$ exact) versus contiguous window tiling on \textit{human\_nontata\_promoters} ($0.992$ at $\ge50\%$, but $0.000$ exact)---while \textit{demo\_coding\_vs\_intergenomic\_seqs} is coordinate-clean ($0.006$) yet containment-borderline, its leakage being coding-paralog homology with no coordinate signature at all. Coordinates can therefore escalate a verdict but must never clear one, and the sequence detectors remain necessary.

\subsection{Adding and removing the construction defect creates and cures the pathology}\label{sec:r-manip}
% construction_manipulation.csv
Because only the positive class carries duplicated coordinates, both interventions perturb dataset size and class balance unless corrected---collapsing duplicates takes \textit{human\_enhancers\_ensembl} from $50/50$ to $34.6\%$ positive (majority baseline $0.500\to0.654$), and duplicating positives gives \textit{human\_ocr\_ensembl} $65.4\%$ positives and $47\%$ more rows. We therefore report as primary the arms in which the intervention and its control are matched on both size and balance, so that they differ solely in whether near-duplicates are present. Applying the omitted merge step to \textit{human\_enhancers\_ensembl} collapses its leak fraction from $0.390$ to $0.012$ and its random-forest inflation from $+0.165$ to $-0.008$---a null---and the ranking inversion disappears, the forest sitting at rank~4 both before and after correction. Conversely, imposing the same construction defect on the merged, clean \textit{human\_ocr\_ensembl}, at identical size and balance, raises its leak fraction from $0.004$ to $0.204$ and its random-forest inflation from $+0.002$ to $+0.105$, and manufactures the inversion: the forest is promoted from rank~4 to rank~1 on the contaminated split and demoted to rank~4 again by correction---the precise syndrome documented in \S4.3. Both effects are larger under matching than without it, so the confounds were suppressing rather than creating the result. Editing coordinates alone, with sequences, labels, model code, split ratio, size and balance all held fixed, both creates and cures the pathology, which is the causal claim the correlational signatures of \S\ref{sec:r-coord} cannot make on their own. One caveat is worth stating plainly: duplicated rows scattered across a random split are leaky by construction, so the break-a-clean direction is not surprising in itself; its content is that the full downstream syndrome, including the memorizer's promotion to rank~1, follows from the construction step alone.

\subsection{An independently built suite carries the same defect, and its own revision removes it}\label{sec:r-census}
% crosssuite_census.csv
Applying the identical census to the Nucleotide Transformer downstream tasks shows the phenomenon is not confined to Genomic Benchmarks. Of $13$ tasks in the original release, four are leaky and three borderline; \textit{enhancers} and \textit{enhancers\_types} carry $25.0\%$ test-to-train leakage that is \emph{byte-identical}, and \textit{splice\_sites\_acceptors} and \textit{\_donors} $0.244$ and $0.245$ at Jaccard $0.7$. We verified the enhancer figure on a separate code path that uses no $k$-mers at all: of $400$ test sequences, exactly $100$ are byte-identical to a training sequence, with label concordance $1.000$, and the training set itself holds $14{,}968$ rows on $14{,}002$ unique sequences. All $13$ tasks of the authors' own revised release are clean. That contrast must be drawn carefully, because sequence length also changed between releases on eight of the thirteen tasks, and $8$-mer Jaccard falls monotonically as sequences lengthen; the \textit{enhancers} task in particular was rebuilt from $200$\,bp to $400$\,bp windows, so its cleanliness cannot be attributed to curation alone and we do not claim it. The controlled comparison is the length-matched subset: \textit{splice\_sites\_acceptors} and \textit{\_donors} are $600$\,bp in \emph{both} releases, and their leakage falls from $0.2435$ and $0.2452$ to $0.0007$ and $0.0010$ under the length-blind metric and from $0.372$ and $0.370$ to $0.007$ under the length-robust one. With sequence length held fixed, changing only how the split was built removes the leakage---the remedy this paper advocates, demonstrated by a third party who did not set out to test it. One pre-registered expectation failed and we report it as such: we predicted the original release would be leaky as a \emph{suite}, whereas only four of thirteen tasks are, and its promoter tasks are clean ($0.005$--$0.015$). That failure is itself informative, since the leakage of \textit{human\_nontata\_promoters} at $0.406$ is therefore not a property of the promoter task but of Genomic Benchmarks' construction of it, which separates task effect from curation effect and corroborates \S\ref{sec:r-coord}. Leakage is a property of particular constructions, not of suites or of subject matter. Finally we emphasise scope: this is a leak \emph{census}, establishing that the precondition for ranking inversion is widespread across suites, and not a demonstrated re-ranking on the second suite---no model is trained on these tasks here---so the ranking-inversion result itself remains the single-dataset existence proof of \S4.3.

\subsection{The audit runs as an executable standard}\label{sec:r-certify}
% certify_self_validation.csv, certify_report_stark.json
\texttt{certify --self-validate} recomposes this paper's eight dataset verdicts from committed intermediate results and reproduces all eight, exiting non-zero on any drift; it is the repository's regression gate. We are precise about what that gate demonstrates: it re-runs no similarity computation and fits no model, and for seven of the eight datasets it applies the same threshold to the same column that produced the original verdict, so those are consistency checks. Its non-trivial content is the composition step, which derives the \emph{borderline} level for \textit{demo\_coding\_vs\_intergenomic\_seqs} from full-scale containment---a verdict the existing report-card code cannot express and that the paper otherwise assembles by hand. The full eight-check path has been executed end to end on one dataset, \textit{drosophila\_enhancers\_stark}, where every check returns a state that can move the verdict: MMseqs2 agrees, residual leak after re-splitting is $0.000$, the graded gap is flagged low-confidence because its high-similarity bin holds ten sequences, the matched random re-split shows the drop is repartitioning cost, and the random-forest drop of $0.0235$ carries a cluster-bootstrap CI of $[-0.007,0.053]$ that includes zero---agreeing with the frozen value and with the clean verdict. The protocol caught two defects in itself, which we report because they illustrate why a green verdict must carry the heavier burden. An early version computed that drop interval by resampling only the original arm and holding the corrected accuracy fixed, discarding half the variance and turning the null drop significant; and it escalated this clean dataset to borderline on a memorizer gap of $0.197$ measured over that ten-sequence bin. Resampling both arms, and requiring a populated bin, an excess over the random-resplit control, and an interval excluding zero before the tripwire may fire, restores the correct verdict.
